# The Data Stewardship Wizard (DSW) 

Tool allows you to create various documents (typically a Data Management Plan, DMP) according to a selected template via questionnaires and the system can be configured to send the document directly to an external service. The process is often such that someone should review the document and give feedback on it. The goal of this is to design and develop a service that can receive documents from DSW (there are already examples, called submission services) and allow reviewers to give feedback on documents, which authors can then read and possibly respond to (in the form of comments/discussion).

Used technologies: 
- Python (FastAPI) - backend 
- TypeScript (Angular) - frontend

Required technologies/procedures: 
- Docker
- CI/CD,
- Git,
- PostgreSQL

In the project I was a backend developer whose main task was to make services, but I also wrote code in other modules of the program. I also wrote tests and did code review of the other project participants.
Also in the project I worked on documentation and the main part of my work was creating the business logic.

This project was in an SP1 and SP2 course (Sowtware Team Project) that lasted for a full two semesters.
