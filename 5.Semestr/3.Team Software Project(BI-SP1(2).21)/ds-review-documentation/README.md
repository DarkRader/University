# Documentation

## About the App

Data Stewardship Review (DSR for short) is an App allowing reviews of data managment plans generated by [Data Stewardship Wizard](https://ds-wizard.org/). Once a document is submitted (through DSW), reviewers assigned to it may leave comments and evaluations of the document. Users then can start discussions about these comments.

## Prerequisites

**In order to run DS Review, you have to be a member of the project group ds-review. This is necessary to access the gitlab container registry.** To gain access, contact the group owner/admin.

You'll also need [Docker](https://www.docker.com/) installed.

## How to Run

1. Clone this repository (Documentation). Then switch to this directory.

2. Login to the gitlab registry. You can do so using ```docker login gitlab.fit.cvut.cz:5050```

3. Download the docker image:
```bash
docker compose pull
```

4. Run the docker image:
```bash
docker compose up
```

5. If you want to change which version you're running, you can do so by editting image tags in docker-compose.yml based on what branches do you want to run (eg. master). To change this, edit lines 17, 31. For example, instead of `:master` use `:v-0.x` (tag). For the correct name check the container registry, because characters like "/" or "_" get replaced by "-".

## Ports

- You can afterwards acces the frontent on the address ```http://localhost:4200/```
- The backend runs on the address ```http://localhost:8000```

## Accessing the Documentation

You can access the API documentation generated by FastAPI by going to ```http://localhost:8000/docs```. The Backend container must be running for this to work.
You can also find some documentation in the Wiki pages of this repository.

## Submitting Using DSW

### Adding a New Submission Service
To submitt using DSW, you need to add a new Submission service in DSW:
1. Go to Administration -> Settings -> Content Settings -> Document Submission and click "+Add service"
2. Fill in the ID, name ("ds-review" for example) and description
3. Add a format: For example: Click "+Add format" and choose "dsw:horizon-europe-dmp", 1.3.0 and HTML
4. Add a user property: Click "+Add property" and type `token` into the field
5. Fill the Request parameters: 
    1. Method: POST
    2. URL: http://127.0.0.1:8000/documents/submit
    3. Header: Click "+Add header" and into header type `x-dsr-token` and into value type `${token}`

![](https://gitlab.fit.cvut.cz/ds-review/documentation/-/raw/master/dsr_submission.PNG "How to setup a new Submission Service")

### Setting Your DSR Token
After registering, your DSR token will be generated. You can access your token when logged in. Copy this token and paste it into your Submission Settings. You can access those either by clicking you profile picture and selecting "Edit profile" and then "Submission Settings" or by selecting Administration -> Users -> Selecting your User -> Submission Settings. Paste your DSR token and click save.

![](https://gitlab.fit.cvut.cz/ds-review/documentation/-/raw/master/dsr_token.PNG "How to setup your DSR token")

Now when submitting through DSW you may select DSR as a submission service.
