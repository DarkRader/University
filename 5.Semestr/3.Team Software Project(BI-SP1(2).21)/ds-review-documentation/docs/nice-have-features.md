# Nice to Have Features Wishlist

This is a list of features, that weren't added during the first year of developement in SP1/2. It may serve as inspiration to those who come after us:
- User notifications: Send email notifications to users, when something changes about their content (their document has been evaluated, new comment, comment resolved, added to a document as a reviewer).
- Make the frontend even more beautiful.
- Add a super user (admin) which will manage the permissions to each document. They should assign reviewers to each document.
- Separate the endpoint for posting a comment into an endpoint for creating a discussion and for posting a comment. Also clear up how these work with evaluations.
